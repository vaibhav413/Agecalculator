# Age Calculator

## About the Project
I developed an Age Calculator web application using HTML, CSS, and JavaScript. It calculates a person's age in years, months, and days based on their date of birth.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub Pages

## Features
- Calculates age in years, months, and days.
- Validates the date of birth.
- Prevents future dates.
- Provides a simple and responsive user interface.

## How to Run Locally
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Enter your date of birth and click **Calculate Age**.

## How to Deploy Using GitHub Pages
1. Create a repository on [GitHub](https://github.com/).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root folder.
3. Open your repository on GitHub.
4. Go to **Settings**.
5. Select **Pages** from the sidebar.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select the `main` branch and the `/(root)` folder.
8. Click **Save**.
9. Wait for the deployment to complete.
10. Open the URL displayed in the GitHub Pages section to access your application online.
